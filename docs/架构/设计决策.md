# 设计决策 (ADR)

记录项目中影响全局的关键设计决策。

## 1. WPF in SolidWorks TaskPane

**背景**：SolidWorks TaskPane 只接受 WinForms 控件，但 WPF 提供更好的 UI 能力。

**决策**：通过 `ElementHost` 嵌入 WPF，并安装 `WH_GETMESSAGE` 键盘钩子修复输入问题。

**理由**：SW 主窗口发送 `WM_KILLFOCUS` 导致 WPF HWND 丢失 `WM_CHAR`。钩子拦截键盘消息并重定向到 WPF HWND。v0.1.2 优化为先 `Marshal.ReadInt32` 快速读消息类型，仅在键盘消息时做完整封送，解决掉帧问题。

## 2. COM 注册双轨制

**背景**：托管 DLL 注册失败时 SW 无法加载插件，但不应导致崩溃。

**决策**：主力 RegAsm（托管 DLL）+ 降级 regsvr32（原生 C++ 垫片）。

**理由**：如果托管 DLL 未注册，SwNativeShim 被加载，安全地接受 ConnectToSW 但不执行任何 UI 操作，仅写日志提示用户运行 RegAsm。

## 3. 特征建模抽象层

**背景**：标准件预览和实际建模需要共享几何描述。

**决策**：定义平台无关的 Profile + ModelFeature 模型，同时服务于 3D 预览（PreviewRenderer）和实际建模（ParametricBuilder）。

**理由**：解耦 UI 预览与 SW API 调用，便于扩展新的特征类型。

## 4. 更新系统架构

**背景**：插件分发到多台机器，需要安全的自动更新机制。

**决策**：

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 配置拆分 | user_config.json + plugin_meta.json | 用户设置 preserve，版本元数据随包覆盖 |
| 多源策略 | auto: Gitee 主 + GitHub 备 | 国内用户 Gitee 快，海外有 GitHub |
| 安全措施 | SHA256 + Zip Slip + TLS 1.2 + UseProxy=false | 防篡改、防路径穿越、防代理挂起 |
| 离线支持 | 手动选本地 ZIP + SHA256 校验 | 局域网环境友好 |
| UI 状态机 | 5 态按钮 | 防重复下载、防误操作 |
| 安装方式 | update.bat（Iteration 1） | 简单可靠，Iteration 2 切 Updater.exe |

## 5. Builder 模式重构

**背景**：v0.1.1 的 ParametricBuilder 用硬编码 switch 处理 5 种模板，难以扩展。

**决策**：引入 IPartBuilder 接口，每种零件一个独立 Builder 类。

**理由**：新增零件类型只需创建一个 Builder 文件，不修改现有代码。9 个 Builder 已验证此模式。
