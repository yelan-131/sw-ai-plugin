# 开发指南 — 环境搭建

> 开发环境配置、调试方法、编码规范

---

## 开发环境

| 工具 | 版本 | 用途 |
|------|------|------|
| Visual Studio 2022 | 17.x | C# / C++ 开发（或 VS Code + C# 扩展） |
| .NET SDK | 8.0+ | 构建 SwComAddin |
| Python | 3.8+ | 运行/调试 AI 后端 |
| SolidWorks | 2020+ | 插件宿主，必须是已安装并激活的版本 |

## 目录约定

```
SwComAddin/
├── Services/           # 业务逻辑（SwConnector, UpdateService, Builders/...）
├── Views/              # UI 逻辑（MainTaskPaneView 的 6 个 partial class）
├── Models/             # 数据模型（StandardPart, UpdateManifest, ...）
├── Helpers/            # 辅助工具（UIHelpers）
├── Data/               # 运行时数据（standard_parts.json, custom_library.json）
└── bin/Debug/net48/    # 构建输出 + 注册目录
```

## 编码规范

- **语言**：C# 代码用英文注释，用户可见字符串用中文
- **命名**：PascalCase（类/方法/属性）、camelCase（局部变量/参数）、_camelCase（私有字段）
- **Partial class**：MainTaskPaneView 按功能拆为 6 个 .cs 文件
- **JSON 字段**：snake_case（与 Python 后端保持一致）
- **日志**：UpdateLogger 用 JSON Lines，桌面 SwAddin.log 用纯文本

## 调试 SolidWorks 插件

SW 插件运行在 SLDWORKS.exe 进程内，调试步骤：

1. **注册 Debug 版本**：
   ```bash
   cd SwComAddin
   register.bat
   ```

2. **VS 附加进程**：
   - 打开 Visual Studio
   - 调试 → 附加到进程 → 选择 `SLDWORKS.exe`
   - 在代码中设置断点

3. **查看日志**：
   - 桌面 `SwAddin.log` — 插件主日志
   - `%LOCALAPPDATA%\SwAiPlugin\logs\update.log` — 更新日志

4. **常用调试场景**：
   - COM 连接问题 → 看 SwAddin.ConnectToSW
   - 键盘输入问题 → 看 SwTaskPaneControl 键盘钩子
   - 更新流程 → 看 UpdateLogger 输出
