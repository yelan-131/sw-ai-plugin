# 技术栈

| 层级 | 技术 | 版本 | 用途 |
|------|------|------|------|
| COM 插件 | C# / .NET Framework | net48 | 嵌入 SolidWorks 的 TaskPane 插件 |
| UI 框架 | WPF + WinForms (ElementHost) | System.Windows | 6 页签主界面 + 键盘修复 |
| SW 互操作 | SolidWorks.Interop.sldworks | 本地安装版本 | 调用 SW API 建模 |
| HTTP 客户端 | System.Net.Http.Json | net48 内置 | 插件 ↔ Python 后端通信 |
| JSON 序列化 | System.Text.Json | 8.0.5 | 标准件库/配置/manifest 读写 |
| AI 后端 | Python / FastAPI | 3.x | 自然语言 → SW 命令解析 |
| AI 模型 | Anthropic Claude Sonnet | claude-sonnet-4-6 | 中文指令理解 |
| 原生垫片 | C++ / Win32 COM | MSVC | 安全降级兜底 |
| 宏启动器 | VB.NET | - | 备用启动方式 |
| 版本管理 | SemanticVersion (自实现) | SemVer 2.0 | 插件版本号解析与比较 |
| 更新日志 | UpdateLogger (自实现) | JSON Lines | 更新流程结构化日志，1MB 自动轮转 |
