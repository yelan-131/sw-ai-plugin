# 更新模块交互设计

> 面向 SolidWorks 插件更新系统的完整交互规范。
> 核心原则：**零弹窗**，所有交互在底部状态栏和内联面板中完成。

---

## 设计原则

1. **零弹窗** — 不使用 MessageBox / Popup，所有状态变化在状态栏和内联面板展示
2. **状态栏为中心** — 版本号即入口，版本号变色即通知
3. **用户主动** — 自动检查仅变色提示，不强制展开面板
4. **可中断** — 下载可取消，稍后提醒可自定义时长
5. **手动检查内聚** — Tab5 手动检查的所有交互都在 Tab5 内完成，不弹出底部面板

---

## 底部状态栏布局

```
┌─────────────────────────────────────────────────────────┐
│  v0.1.3              ● ● ●                    ⚙        │
│  ↑ 版本号         ↑ 连接信号              ↑ 设置按钮    │
└─────────────────────────────────────────────────────────┘
```

### 三区职责

| 区域 | 位置 | 内容 | 交互 |
|------|------|------|------|
| 版本号 | 左侧 | `vX.Y.Z`，有更新时变蓝色 | 有更新→展开面板；无更新→跳转 Tab5 |
| 连接信号 | 中间 | 三个圆点：AI / 标准件 / 模型库 | 悬停显示 tooltip |
| 设置按钮 | 右侧 | ⚙ 图标 | 点击切换到 Tab5 |

### 版本号点击行为

| 状态 | 点击行为 |
|------|---------|
| 无更新 | 跳转到 Tab5 系统设置页 |
| 有更新（面板收起） | 展开底部 UpdatePanel |
| 有更新（面板展开） | 收起底部 UpdatePanel |

### 版本号状态

| 状态 | 显示 | 颜色 |
|------|------|------|
| 正常 | `v0.1.3` | 灰色 #666 |
| 有更新 | `v0.1.3 → v0.2.0 ↗` | 蓝色 #0078D7 |
| 下载中 | `↓ 65%` | 蓝色 #0078D7 |
| 就绪 | `v0.1.3 ✓就绪` | 蓝色 #0078D7 |
| 更新后首次启动 | `v0.2.0 ✓` | 绿色 #2E7D32，3 秒后恢复灰色 |
| 检查失败 | `v0.1.3 ⚠` | 橙色 #FF8F00 |

### 连接信号

| 圆点 | 含义 | 绿色条件 | 灰色条件 |
|------|------|----------|----------|
| 第1个 | AI 后端 | `/api/health` 返回 200 | 连接失败 |
| 第2个 | 标准件数据 | `Data/standard_parts.json` 存在 | 文件缺失 |
| 第3个 | 模型库 | 路径已配置且目录存在 | 未配置 |

悬停显示文字示例：`AI 后端 · 已连接` / `标准件 · 数据缺失`

## 自动更新流程（底部 UpdatePanel）

### Step 1：启动 — 正常状态

```
┌─────────────────────────────────────────────┐
│                                             │
│              (主界面内容区)                   │
│                                             │
├─────────────────────────────────────────────┤
│  v0.1.3          ● ● ●            ⚙        │
└─────────────────────────────────────────────┘
```

- 插件加载完成后，延迟 15 秒执行一次更新检查
- 之后按 `check_interval_hours`（默认 4h）周期检查
- 状态栏始终可见，不打断用户操作

### Step 2：发现新版本 — 版本号变色

```
┌─────────────────────────────────────────────┤
│  v0.1.3 → v0.2.0 ↗    ● ● ●        ⚙     │
│  ~~~~~~~~~~~~~~~~~~~~~                       │
│  蓝色 #0078D7，带淡入动画 1s                  │
└─────────────────────────────────────────────┘
```

- 版本号从灰色变为蓝色，右侧显示新版本号和 ↗ 箭头
- **不自动展开面板**，仅变色提示
- 用户可继续正常使用，不受打扰

### Step 3：点击版本号 — 展开更新面板

```
┌─────────────────────────────────────────────┐
│              (主界面内容区，高度压缩)          │
├─────────────────────────────────────────────┤
│  v0.1.3 → v0.2.0 ↗    ● ● ●        ⚙     │
├─────────────────────────────────────────────┤  ← 展开区
│  v0.2.0 · 2026-05-15 · 4.2MB · 源: gitee  │
│                                             │
│  ■ 新功能                                   │
│    1. 新增齿轮参数化模板                      │
│    2. 智能助手支持命令执行                     │
│  ■ 修复                                     │
│    1. 标准件预览闪烁问题                      │
│                                             │
│               [稍后提醒 ▾]    [立即更新]      │
└─────────────────────────────────────────────┘
```

- 再次点击版本号 → 收起面板
- 按 ESC → 收起面板

### Step 4：「稍后提醒」下拉选择

点击「稍后提醒 ▾」弹出下拉菜单（非弹窗）：

```
               ┌──────────────┐
               │  1 小时后     │
               │  4 小时后     │
               │  明天         │
               │  7 天后       │
               └──────────────┘
```

- 选择后写入 `DeferUntilUtc`，到期后版本号重新变蓝
- 面板自动收起，版本号恢复灰色

### Step 5-8：下载 → 安装 → 重启

（与前一版相同，见底部 UpdatePanel 流程图）

## Tab5 手动检查

手动检查入口在 Tab5「系统设置」页。

**核心原则：手动检查的所有交互都在 Tab5 内完成，不弹出底部 UpdatePanel。**

### Tab5 更新区块布局

```
┌─────────────────────────────────────────────┐
│  [Tab5 系统设置]                             │
│  ...（AI 服务、后端服务等）                    │
│                                             │
│  ─── 更新 ─────────────────────────────      │
│  当前版本: v0.1.3                            │
│  检查周期: [4 小时 ▾]                        │
│                                             │
│  [检查更新]                                  │
│  (检查结果在此处展示)                         │
│  (版本选择器在此处展示)                       │
│                                             │
│  ─── 离线更新 ──────────────────────────      │
│  [选择本地 ZIP 文件]                         │
│                                             │
│  ─── 关于 ─────────────────────────────      │
│  SW AI Plugin v0.1.3                        │
│  AI 驱动的 SolidWorks 参数化建模助手          │
└─────────────────────────────────────────────┘
```

**设计决策：**
- 不提供「更新源」选择器 — UpdateService 内部自动选择 gitee → github → mirror 降级策略
- 手动检查只保留「检查周期」和「检查更新」按钮
- 离线更新提供独立的本地 ZIP 安装入口

### 点击「检查更新」→ 有更新

按钮变为「检查中...」禁用状态，检查完成后：
- 按钮恢复为「检查更新」
- 按钮下方显示结果文字（蓝色）
- 同时查询远端最近 5 个 Release，展示版本选择器

```
│  ─── 更新 ─────────────────────────────      │
│  当前版本: v0.1.2                            │
│  检查周期: [4 小时 ▾]                        │
│                                             │
│  [检查更新]                                  │
│  发现新版本 v0.2.0                           │
│                                             │
│  选择版本: ┌──────────────────────┐          │
│           │ ● v0.2.0 (最新)  05-15│          │
│           │   v0.1.3         05-12│          │
│           └──────────────────────┘          │
│                                             │
│  v0.2.0 · 4.2MB · 源: gitee                │
│  v0.2.0 更新模块重设计 + 零弹窗 UI           │
│                                             │
│                        [更新到选定版本]       │
│                                             │
│  ─── 离线更新 ──────────────────────────      │
```

- 选择不同版本 → 下方信息自动切换
- 当前版本标记「(当前)」
- 点击「更新到选定版本」→ 底部 UpdatePanel 展开显示下载进度

### 点击「检查更新」→ 已是最新

```
│  [检查更新]                                  │
│  ✓ 已是最新版本 v0.1.3                       │
│                                             │
│  选择版本: ┌──────────────────────┐          │
│           │ ● v0.1.3 (最新)  05-15│          │
│           │   v0.1.2         05-14│          │
│           │   v0.1.1         05-13│          │
│           └──────────────────────┘          │
│                                             │
│  v0.1.3 · 1.3MB · 源: github               │
│                                             │
│                        [更新到选定版本]       │
```

- 即使已是最新，仍显示版本选择器（支持查看/降级旧版本）
- 当前版本不可操作

### 点击「检查更新」→ 检查失败

```
│  [检查更新]                                  │
│  ✗ 检查失败：无法连接更新服务器                │
```

- 按钮恢复可用，点击即可重试
- 不弹出底部 UpdatePanel

### 离线更新

点击「选择本地 ZIP 文件」→ 打开文件对话框 → 选择 .zip：

```
│  ─── 离线更新 ──────────────────────────      │
│  已选择: SwAiPlugin_v0.2.0.zip (4.2MB)      │
│  ✓ 已就绪，点击下方「保存并安装」完成更新      │
```

选择文件后自动将 ZIP 设为待安装状态，用户通过底部 UpdatePanel 完成安装。

## 签名验证

更新检查流程包含 Ed25519 签名验证：

| 场景 | 行为 |
|------|------|
| manifest.sig 存在且验证通过 | 正常继续 |
| manifest.sig 存在但验证失败 | 拒绝更新，显示"签名验证失败" |
| manifest.sig 不存在 | 记录警告日志，正常继续（向后兼容） |
