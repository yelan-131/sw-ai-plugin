## 核心数据流

### 1. 参数化建模流（本地）

用户选择模板 → 填参数 → 直接调用 SW API 生成零件，不经过网络。

```
用户选择模板 → 填写参数 → MainTaskPaneView 收集
    → ParametricBuilder.BuildXxx(params)
        → SwConnector → ISldWorks.NewPart()
        → ISketchManager.CreateCircle / CreateCornerRectangle
        → IFeatureManager.FeatureExtrusion3 / FeatureCut3
        → IModelDoc2.SaveAs2
```

**涉及文件**：`MainTaskPaneView.xaml.cs` → `ParametricBuilder.cs` → `SwConnector.cs`

### 2. AI 智能建模流（HTTP）

用户输入中文 → 插件转发到 Python 后端 → Claude 解析为命令 JSON → 返回前端展示。

```
用户输入中文 → MainTaskPaneView.AiSendBtn_Click
    → HTTP POST /api/chat { message }
    → SwAiBackend → Claude API (system_prompt + user message)
    → Claude 返回 JSON { reply, commands }
    → 前端显示 reply 文本
    → (未来) 解析 commands → 执行 SW API 调用
```

**涉及文件**：`MainTaskPaneView.xaml.cs` → `SwAiBackend/app.py` → `sw_command_parser.py` → `prompts/system_prompt.txt`

### 3. 标准件浏览流

从 JSON 加载标准件库 → TreeView 展示 → 点击查看详情和 3D 预览 → 插入到 SolidWorks。

```
standard_parts.json → StandardPartsCatalog 反序列化
    → 3 级 TreeView (Category → SubCategory → StandardPart)
    → 用户点击零件 → PartFeatureTemplates.Build(template, specs)
        → FeatureList → PreviewRenderer → Viewport3D 3D 预览
    → 用户点击"插入" → ISldWorks.OpenDoc6
```

**涉及文件**：`Data/standard_parts.json` → `MainTaskPaneView.xaml.cs` → `PartFeatureTemplates.cs` → `PartPreviewView.xaml.cs`

## 关键设计决策

### WPF in SolidWorks TaskPane

SolidWorks TaskPane 只接受 WinForms 控件。插件通过 `ElementHost` 嵌入 WPF，但存在键盘输入问题：

- **根因**：SolidWorks 主窗口发送 `WM_KILLFOCUS` 给 WPF HWND，导致 `HwndSource` 丢弃 `WM_CHAR`
- **修复**：`SwTaskPaneControl` 安装 `WH_GETMESSAGE` 钩子，拦截键盘消息并重定向到 WPF HWND
- **TextInput**：手动处理 `WM_CHAR`，直接修改 `TextBox.Text` 并设置 `CaretIndex`，绕过 WPF 绑定

### COM 注册双轨制

| 方式 | 工具 | 文件 | 用途 |
|------|------|------|------|
| 托管注册 | RegAsm.exe | SwComAddin.dll | 主力，完整功能 |
| 原生垫片 | regsvr32 | SwNativeShim.dll | 降级，仅日志 |

如果托管 DLL 未正确注册，SwNativeShim 会被加载，安全地接受 `ConnectToSW` 但不执行任何 UI 操作，仅写日志提示用户用 RegAsm 注册。

### 特征建模抽象层

`ModelingFeatures.cs` 定义了一套平台无关的特征描述模型：

```
Profile (截面形状)
  ├── CircleProfile    — 直径
  ├── RectangleProfile — 宽 × 高
  └── PolygonProfile   — 边数 + 外接圆直径

ModelFeature (建模操作)
  ├── ExtrudeFeature   — 拉伸凸台
  ├── ExtrudeCutFeature— 拉伸切除
  ├── RevolveFeature   — 旋转
  ├── ChamferFeature   — 倒角
  ├── FilletFeature    — 圆角
  └── HoleFeature      — 打孔
```

这套模型同时服务于两个场景：
1. **3D 预览**：`PreviewRenderer` 根据 FeatureList 生成 WPF Viewport3D 网格
2. **实际建模**：`ParametricBuilder` 直接调用 SW API（当前未使用 FeatureList，而是硬编码 SW API 调用）
