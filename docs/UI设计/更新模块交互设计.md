# 更新模块交互设计

> 面向 SolidWorks 插件更新系统的完整交互规范。
> 核心原则：**零弹窗**，所有交互在底部状态栏和内联面板中完成。

---

## 设计原则

1. **零弹窗** — 不使用 MessageBox / Popup，所有状态变化在状态栏和内联面板展示
2. **状态栏为中心** — 版本号即入口，版本号变色即通知
3. **用户主动** — 自动检查仅变色提示，不强制展开面板
4. **可中断** — 下载可取消，稍后提醒可自定义时长

---

## 底部状态栏布局

```
┌─────────────────────────────────────────────────────────┐
│  v0.1.2              ● ● ●                    ⚙        │
│  ↑ 版本号         ↑ 连接信号              ↑ 设置按钮    │
└─────────────────────────────────────────────────────────┘
```

### 三区职责

| 区域 | 位置 | 内容 | 交互 |
|------|------|------|------|
| 版本号 | 左侧 | `vX.Y.Z`，有更新时变蓝色 | 点击展开/收起更新面板 |
| 连接信号 | 中间 | 三个圆点：AI / 标准件 / 模型库 | 悬停显示 tooltip |
| 设置按钮 | 右侧 | ⚙ 图标 | 点击切换到 Tab5 |

### 版本号状态

| 状态 | 显示 | 颜色 |
|------|------|------|
| 正常 | `v0.1.2` | 灰色 #666 |
| 有更新 | `v0.1.2 → v0.2.0 ↗` | 蓝色 #0078D7 |
| 下载中 | `↓ 65%` | 蓝色 #0078D7 |
| 就绪 | `v0.1.2 ✓就绪` | 蓝色 #0078D7 |
| 更新后首次启动 | `v0.2.0 ✓` | 绿色 #2E7D32，3 秒后恢复灰色 |
| 检查失败 | `v0.1.2 ⚠` | 橙色 #FF8F00 |

### 连接信号

| 圆点 | 含义 | 绿色条件 | 灰色条件 |
|------|------|----------|----------|
| 第1个 | AI 后端 | `/api/health` 返回 200 | 连接失败 |
| 第2个 | 标准件数据 | `Data/standard_parts.json` 存在 | 文件缺失 |
| 第3个 | 模型库 | 路径已配置且目录存在 | 未配置 |

悬停显示文字示例：`AI 后端 · 已连接` / `标准件 · 数据缺失`

## 详细交互步骤

### Step 1：启动 — 正常状态

```
┌─────────────────────────────────────────────┐
│                                             │
│              (主界面内容区)                   │
│                                             │
├─────────────────────────────────────────────┤
│  v0.1.2          ● ● ●            ⚙        │
└─────────────────────────────────────────────┘
```

- 插件加载完成后，后台立即执行一次更新检查
- 之后按 `check_interval_hours`（默认 4h）周期检查
- 状态栏始终可见，不打断用户操作

### Step 2：发现新版本 — 版本号变色

```
┌─────────────────────────────────────────────┤
│  v0.1.2 → v0.2.0 ↗    ● ● ●        ⚙     │
│  ~~~~~~~~~~~~~~~~~~~~~                       │
│  蓝色 #0078D7，带淡入动画 1s                  │
└─────────────────────────────────────────────┘
```

- 版本号从灰色变为蓝色，右侧显示新版本号和 ↗ 箭头
- **不自动展开面板**，仅变色提示
- 用户可继续正常使用，不受打扰

### Step 3：点击版本号 — 展开更新面板

```
┌─────────────────────────────────────────────┐
│              (主界面内容区，高度压缩)          │
├─────────────────────────────────────────────┤
│  v0.1.2 → v0.2.0 ↗    ● ● ●        ⚙     │
├─────────────────────────────────────────────┤  ← 展开区
│  v0.2.0 · 2026-05-15 · 4.2MB · 源: gitee  │
│                                             │
│  ■ 新功能                                   │
│    1. 新增齿轮参数化模板                      │
│    2. 智能助手支持命令执行                     │
│  ■ 修复                                     │
│    1. 标准件预览闪烁问题                      │
│                                             │
│               [稍后提醒 ▾]    [立即更新]      │
└─────────────────────────────────────────────┘
```

- 再次点击版本号 → 收起面板
- 按 ESC → 收起面板
- Release notes 区域可滚动，MaxHeight 不超过面板 50%

### Step 4：「稍后提醒」下拉选择

点击「稍后提醒 ▾」弹出下拉菜单（非弹窗）：

```
               ┌──────────────┐
               │  1 小时后     │
               │  4 小时后     │
               │  明天         │
               │  7 天后       │
               └──────────────┘
```

选择后：

```
┌─────────────────────────────────────────────┤
│  v0.1.2          ● ● ●            ⚙        │
├─────────────────────────────────────────────┤
│  ✓ 将在明天后再次提醒                         │  ← 2 秒后自动消失并收起
└─────────────────────────────────────────────┘
      │
      ▼ 2 秒后
┌─────────────────────────────────────────────┤
│  v0.1.2          ● ● ●            ⚙        │  ← 版本号恢复灰色
└─────────────────────────────────────────────┘
```

- 选择后写入 `DeferUntilUtc`，到期后版本号重新变蓝
- 默认选项：明天（24h）

### Step 5：点击「立即更新」— 下载

```
┌─────────────────────────────────────────────┤
│  ↓ 65%              ● ● ●          ⚙       │
├─────────────────────────────────────────────┤
│  正在下载 v0.2.0...                          │
│                                             │
│  ████████████████░░░░░  65%                 │
│  3.2 MB / 4.8 MB  ·  1.2 MB/s              │
│                                             │
│                                     [取消]   │
└─────────────────────────────────────────────┘
```

- 版本号区域同步显示 `↓ 65%`，一眼可识别状态
- 进度条每 100ms 刷新一次
- 速度显示低于 1MB/s 时隐藏

**点击取消：**

```
├─────────────────────────────────────────────┤
│  ✓ 下载已取消                                │  ← 2 秒后消失
│                     [稍后提醒 ▾]   [重新下载]  │
└─────────────────────────────────────────────┘
```

### Step 6：下载完成 — 安装确认

下载完成 + SHA256 校验通过后，面板自动切换：

**有未保存文档时：**

```
┌─────────────────────────────────────────────┤
│  v0.1.2  ✓就绪      ● ● ●          ⚙      │
├─────────────────────────────────────────────┤
│  ✓ 下载完成，SHA256 校验通过                  │
│                                             │
│  安装需要关闭 SolidWorks                     │
│  检测到未保存文档（将自动保存）：              │
│    • 零件1.SLDPRT                            │
│    • 装配体.SLDASM                           │
│                                             │
│                       [取消]  [保存并安装]    │
└─────────────────────────────────────────────┘
```

**没有未保存文档时：**

```
│  所有文档已保存 ✓                            │
│                                             │
│                       [取消]  [立即安装]      │
```

### Step 7：点击「保存并安装」— 自动完成

用户点击后，插件按顺序执行：

1. 自动保存所有脏文档（`IModelDoc2.Save()`）
2. 准备更新包（解压、Zip Slip 防护、生成 bat）
3. 启动 bat（后台，隐藏窗口）
4. 调用 `ISldWorks.ExitApp()` 退出 SolidWorks

**用户视角：** 点了按钮 → SW 自动保存 → SW 关闭 → 几秒后 SW 重新打开

**bat 后台执行：**
- 检测 SW 已退出（立即，因插件主动退出）
- 备份旧文件
- 复制新文件
- RegAsm 注册
- 写入 plugin_meta.json
- 重启 SLDWORKS.exe
- 清理临时目录

### Step 8：重启后 — 更新成功

```
┌─────────────────────────────────────────────┤
│  v0.2.0 ✓          ● ● ●          ⚙       │
│  ~~~~~~~~~~~~                               │
│  绿色 #2E7D32，带 ✓ 标记                     │
└─────────────────────────────────────────────┘
      │
      ▼ 3 秒后
┌─────────────────────────────────────────────┤
│  v0.2.0            ● ● ●          ⚙       │  ← ✓ 消失，恢复灰色
└─────────────────────────────────────────────┘
```

- 检测方式：启动时比较 `plugin_meta.json` 中的 version 与上次记录的 version
- 仅在版本号变更时显示 ✓ 标记

```
│                                             │
│                       [取消]  [立即安装]      │
```

如果无远端 manifest（离线场景），跳过 SHA256 对比，直接进入安装流程。

## 异常流程

### 下载失败

```
┌─────────────────────────────────────────────┤
│  v0.1.2  ⚠         ● ● ●          ⚙      │
├─────────────────────────────────────────────┤
│  ✗ 下载失败：SHA256 校验不一致               │
│  错误码：UPD-VERIFY-HASH                    │
│                                             │
│  [稍后提醒 ▾]    [重试]    [手动下载 ↓]      │
└─────────────────────────────────────────────┘
```

「手动下载 ↓」展开：

```
│  选择更新包来源：                             │
│  [GitHub Release]  [Gitee Release]  [本地ZIP] │
```

GitHub / Gitee → 打开浏览器到 Release 页面
本地 ZIP → 文件对话框 → 选 .zip → 校验 → 安装

### 网络不通

```
┌─────────────────────────────────────────────┤
│  v0.1.2  ⚠         ● ● ●          ⚙      │
├─────────────────────────────────────────────┤
│  ✗ 无法连接更新服务器                        │
│  将在 4 小时后自动重试                        │
│                                             │
│                        [关闭]    [重试]      │
└─────────────────────────────────────────────┘
```

### 无新版本（手动检查时）

版本号闪绿光 1 秒，Tab5 内显示"已是最新"。

## 签名验证

更新检查流程包含 Ed25519 签名验证：

| 场景 | 行为 |
|------|------|
| manifest.sig 存在且验证通过 | 正常继续 |
| manifest.sig 存在但验证失败 | 拒绝更新，显示"签名验证失败" |
| manifest.sig 不存在 | 记录警告日志，正常继续（向后兼容） |

签名验证失败时：

```
┌─────────────────────────────────────────────┤
│  v0.1.2  ⚠         ● ● ●          ⚙      │
├─────────────────────────────────────────────┤
│  ✗ 更新包签名验证失败                        │
│  可能已被篡改，建议从官方渠道重新下载           │
│                                             │
│  [稍后提醒 ▾]          [手动下载 ↓]          │
└─────────────────────────────────────────────┘
```
