# 用户手册 — 快速入门

> 面向 SolidWorks 终端用户的使用说明

---

## 安装

1. 获取安装包 `SwAiPlugin_vX.Y.Z.zip`
2. 解压到任意目录（如 `C:\SwAiPlugin\`）
3. 以管理员身份运行 `install.bat`
4. 启动 SolidWorks

## 首次使用

1. 打开 SolidWorks
2. 菜单：工具 → 插件 → 勾选 "SolidWorks AI Plugin"
3. 右侧 TaskPane 出现插件面板

## 五大功能

| 功能 | 页签 | 说明 |
|------|------|------|
| 标准件浏览 | Tab1 | 浏览 40+ 种标准件，3D 预览，一键插入 |
| 自定义库 | Tab2 | 管理自己的零件和模板 |
| 参数建模 | Tab3 | 选模板填参数，自动生成零件 |
| 智能助手 | Tab4 | 用中文描述需求，AI 生成建模命令 |
| 系统设置 | Tab5 | 配置 API Key、后端地址、查看连接状态 |

## 更新插件

插件会每 4 小时自动检查更新。也可以手动检查：

1. 点击底部版本号 → 弹出版本弹窗
2. 点击「检查更新」
3. 如有新版本，底部出现蓝点
4. 点击蓝点展开更新面板，查看更新日志
5. 点击「立即更新」→ 下载 → 确认关闭 SW → 自动安装

## 常见问题

**Q: 插件不显示在 TaskPane？**
确认已以管理员权限运行 `install.bat`。

**Q: 智能助手无法使用？**
需要先在 Tab5 配置 Anthropic API Key，并确保 Python 后端已启动。

**Q: 标准件点击插入后没反应？**
部分零件尚未生成 .sldprt 文件，可使用 Tab3 参数建模代替。
