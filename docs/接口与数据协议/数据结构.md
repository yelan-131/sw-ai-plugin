# 数据结构

## 标准件数据结构

`Data/standard_parts.json` 格式：

### JSON 格式示例

```json
{
  "categories": [
    {
      "name": "紧固件",
      "icon": "bolt",
      "subcategories": [
        {
          "name": "六角头螺栓",
          "parts": [
            {
              "id": "hex_bolt_m6",
              "name": "六角头螺栓 M6",
              "standard": "GB/T 5782",
              "geometric": true,
              "feature_template": "hex_bolt",
              "specs": { "d": 6, "s": 10, "k": 4.0, "r": 0.25 },
              "performance": {},
              "file_path": "",
              "description": "标准六角头螺栓，M6螺纹"
            }
          ]
        }
      ],
      "parts": []
    }
  ]
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | 是 | 唯一标识符，也用作插入时的文件名 |
| `name` | string | 是 | 界面显示名称 |
| `standard` | string | 是 | 国标号或标准名 |
| `geometric` | bool | 是 | 是否有几何模型（传感器等为 false） |
| `feature_template` | string? | 否 | 对应 `PartFeatureTemplates` 的方法名 |
| `specs` | object | 是 | 尺寸参数键值对 |
| `performance` | object | 否 | 性能参数（载荷/转速等） |
| `file_path` | string | 否 | 零件文件路径（当前为空，待生成） |
| `description` | string | 是 | 中文描述 |

### TreeView 数据层级

```
Category (1级: 紧固件/轴承/电机/气缸/传感器/导轨)
  └── SubCategory (2级: 六角头螺栓/螺母/垫圈/...)
        └── StandardPart (3级: 具体规格零件)
```

如果 Category 只有 `parts` 没有 `subcategories`，加载时会自动包装为一个同名 SubCategory。

## 特征建模数据结构

`ModelingFeatures.cs` 定义的平台无关特征模型。

### Profile（截面）

```csharp
abstract class Profile { }
class CircleProfile : Profile { double Diameter; }
class RectangleProfile : Profile { double Width, Height; }
class PolygonProfile : Profile { int Sides; double Diameter; }
```

### ModelFeature（特征）

```csharp
abstract class ModelFeature { }

class ExtrudeFeature : ModelFeature {
    Profile Profile; double Depth; ExtrudeDirection Direction;
    double OffsetX, OffsetY; string Plane, MergeRule;
}

class ExtrudeCutFeature : ModelFeature {
    Profile Profile; double Depth; double OffsetX, OffsetY; string Plane;
}

class RevolveFeature : ModelFeature {
    Profile Profile; double Angle; string Plane;
}

class ChamferFeature : ModelFeature { double Size; string Edge; }
class FilletFeature : ModelFeature { double Radius; string Edge; }
class HoleFeature : ModelFeature {
    double Diameter, Depth, PositionX, PositionY; string Plane;
}
```

### FeatureList（特征脚本）

```csharp
class FeatureList {
    List<ModelFeature> Features;
    void AddExtrude(Profile, depth, plane, merge, offsetX, offsetY);
    void AddExtrudeCut(Profile, depth, plane, offsetX, offsetY);
    void AddRevolve(Profile, angle, plane);
    void AddChamfer(size, edge);
    void AddFillet(radius, edge);
    void AddHole(diameter, depth, posX, posY, plane);
}
```
