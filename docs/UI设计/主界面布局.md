# 主界面布局

> 概述 SwComAddin 的整体 UI 结构和导航机制。

---

## 整体结构

主界面 `MainTaskPaneView` 是一个 WPF UserControl，嵌入 SolidWorks 右侧 TaskPane。

```
┌─────────────────────────────────┐
│  [Tab1] [Tab2] [Tab3] [Tab4] [Tab5] │  ← 顶部 Tab 导航（RadioButton）
├─────────────────────────────────┤
│                                   │
│           当前页签内容              │  ← 内容区域（PageParts / PageCustom / ...）
│                                   │
├─────────────────────────────────┤
│  [状态栏] [版本号] [?] [蓝点]     │  ← 底部 Footer
└─────────────────────────────────┘
```

## 6 个页签

| 页签 | 名称 | 内容 | 详细文档 |
|------|------|------|---------|
| Tab1 | 标准件库 | 3 级 TreeView + 3D 预览 + 插入 | [Tab1-标准件库](Tab1-标准件库.md) |
| Tab2 | 自定义库 | 用户零件/模板管理 | [Tab2-自定义库](Tab2-自定义库.md) |
| Tab3 | 参数建模 | 9 种模板 → SW API 生成 | [Tab3-参数建模](Tab3-参数建模.md) |
| Tab4 | 智能助手 | 中文→Claude→命令 JSON | [Tab4-智能助手](Tab4-智能助手.md) |
| Tab5 | 系统设置 | API Key + 连接状态 + 更新 | [Tab5-系统设置](Tab5-系统设置.md) |
| Tab6 | 帮助 | 帮助信息 | [Tab6-帮助页](Tab6-帮助页.md) |

## 底部 Footer

- **状态栏**：AI OK / 标准件 OK / 模型库 OK（三色指示灯）
- **版本号**：`vX.Y.Z`，点击弹出版本弹窗
- **帮助按钮** `[?]`：切换到 Tab6
- **更新蓝点**：检测到新版本时显示，点击展开更新面板

## 导航机制

Tab 使用 `RadioButton` 实现，通过 `Checked` 事件切换 `Visibility`：

```
TabParts_Checked → ShowPage(PageParts)
TabCustom_Checked → ShowPage(PageCustom)
...
```

## 键盘交互

- **ESC**：关闭版本弹窗 或 收起更新面板（优先弹窗）
- **Tab**：焦点导航
