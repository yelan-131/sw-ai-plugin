# 配置


### API Key

在插件的"系统设置"页签中：
1. 输入 Anthropic API Key
2. 点击"保存"
3. 点击"验证"确认连接

或设置环境变量：
```bash
set ANTHROPIC_API_KEY=sk-ant-api03-xxxxx
```

### 后端地址

默认 `http://localhost:8765`，可在设置页签修改并保存。

### 更新配置

在 Tab5 系统设置或 `user_config.json` 中配置：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| update_source | auto | 更新源：auto（Gitee 主 + GitHub 备）/ gitee / github / mirror |
| check_interval_hours | 4 | 自动检查更新周期（小时） |
| receive_prerelease | false | 是否接收 Beta 通道版本 |
| mirror_url | null | 企业镜像 URL，非空时强制使用此源 |
| skipped_versions | [] | 用户跳过的版本列表 |
| defer_until_utc | null | "稍后提醒"到期时间（UTC ISO8601） |

**三条更新路径：**

| 路径 | 场景 | 流程 |
|------|------|------|
| 自动更新 | 有网，检测到新版本 | 下载 → SHA256 校验 → 确认 → update.bat |
| 手动选包 | 局域网，已有 ZIP | 浏览选 ZIP → SHA256 校验 → update.bat |
| 引导下载 | 局域网，未下载 | 点击 GitHub/Gitee 链接 → 浏览器下载 → 回来选包 |
