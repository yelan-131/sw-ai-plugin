# 配置文件

## 配置文件

### 用户配置 (user_config.json)

位于 SwComAddin 输出目录。用户私有运行时设置，更新流程 preserve（不覆盖），不随发布包发布。

```json
{
  "backend_url": "http://localhost:8765",
  "model_library_path": "",
  "update_source": "auto",
  "skipped_versions": [],
  "defer_until_utc": null,
  "check_interval_hours": 4,
  "receive_prerelease": false,
  "mirror_url": null
}
```

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| backend_url | string | "http://localhost:8765" | AI 后端地址 |
| model_library_path | string | "" | 用户模型库路径 |
| update_source | string | "auto" | 更新源：auto / gitee / github / mirror |
| skipped_versions | string[] | [] | 用户主动跳过的版本列表 |
| defer_until_utc | string? | null | "稍后提醒"到期时间（ISO8601 UTC） |
| check_interval_hours | int | 4 | 自动检查更新周期（小时） |
| receive_prerelease | bool | false | 是否接收 Beta 通道版本 |
| mirror_url | string? | null | 企业镜像 URL，非空时强制使用此源 |

### 插件元数据 (plugin_meta.json)

位于 SwComAddin 输出目录。随发布包覆盖，由 Updater 在更新成功后写入，主插件运行中只读。

```json
{
  "schema": "1.0",
  "version": "0.1.2",
  "channel": "stable",
  "build_date": "2026-05-14T17:52:32Z",
  "update_repo": "yelan-131/sw-ai-plugin",
  "gitee_repo": "yelan1387/sw-ai-plugin"
}
```

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| schema | string | "1.0" | 数据格式版本 |
| version | string | "0.1.1" | 当前安装版本（SemVer） |
| channel | string | "stable" | 发布通道（stable / beta / dev） |
| build_date | string | "" | 构建时间 |
| update_repo | string | "yelan-131/sw-ai-plugin" | GitHub 更新仓库 |
| gitee_repo | string | "yelan1387/sw-ai-plugin" | Gitee 更新仓库 |

### 旧版迁移

v0.1.1 及更早版本使用单一 `plugin_config.json`。插件启动时 `PluginConfigService` 自动检测并迁移：

1. 读取旧 `plugin_config.json` 内容
2. 拆分为 `user_config.json`（用户设置）和 `plugin_meta.json`（版本元数据）
3. 旧文件重命名为 `plugin_config.json.legacy.bak`

迁移幂等：如果新文件已存在则跳过。迁移失败不致命，保留旧文件供下次启动重试。

### 自定义库 (custom_library.json)

位于 SwComAddin/Data/ 目录，用户自建的零件和模板：

```json
{
  "Parts": [
    {
      "Id": "abc12345",
      "Name": "自定义零件",
      "Category": "分类",
      "Standard": "",
      "Specs": {},
      "Notes": ""
    }
  ],
  "Templates": [
    {
      "Id": "def67890",
      "Name": "自定义模板",
      "Parameters": [
        { "Key": "d", "Label": "直径", "DefaultValue": "10", "Unit": "mm" }
      ]
    }
  ]
}
```

### AI 后端配置 (config.json)

位于 SwAiBackend 目录，存储 Anthropic API Key：

```json
{ "anthropic_api_key": "sk-ant-api03-xxxxx" }
```

也可通过环境变量 `ANTHROPIC_API_KEY` 设置，优先级高于配置文件。
